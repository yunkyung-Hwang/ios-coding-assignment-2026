# 요구사항

과제 원문은 저장소 README 참조. 아래는 구현·검증 추적을 위해 부여한 ID.
테스트 이름의 `[R-xx]` 접두사가 이 표를 가리킨다.

| ID | 요구사항 |
|---|---|
| R-01 | 상품 목록 조회 |
| R-02 | 목록에서 상품 선택 시 상세 화면으로 이동 |
| R-03 | 찜 등록·해제 |
| R-04 | 앱 재실행 후에도 찜 상태 유지 |
| R-05 | 목록과 상세의 찜 상태 동기화 |
| R-06 | 상세 화면 진입 시 상품 ID로 상세 API 조회 |
| R-07 | 목록 1열·2열 전환. 전환해도 표시 항목 유지 |

## 표시 항목

| 화면 | 항목 |
|---|---|
| 목록 | 상품명 · 가격 · 썸네일 · 찜 여부 · 별점 · 리뷰 수 |
| 상세 | 목록 항목 + 상세설명 · 이미지 전체 |

## 데이터

| 용도 | 엔드포인트 |
|---|---|
| 목록 | `GET https://dummyjson.com/products` |
| 상세 | `GET https://dummyjson.com/products/{id}` |
