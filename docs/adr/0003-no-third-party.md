# ADR-0003: 외부 라이브러리 미사용

상태: 채택

## 맥락
- 의존성 관리 방식 자유
- 사용 시 PR 에 사유 설명 필요

## 결정
- 외부 라이브러리 미사용

## 근거
- 네트워크 — URLSession + async/await
- 상태 관리 — Observation (표준 제공)
- 이미지 — AsyncImage
- 영속화 — FileManager + Codable
- 테스트 — Swift Testing
- 의존성 추가는 빌드 시간·버전 관리·설명 책임을 늘리나 요구사항 범위에서 얻는 이득 없음

## 기각한 대안
- **이미지 로딩 라이브러리(Kingfisher·SDWebImage 등)** — 필요한 기능이 메모리 캐시 한 계층뿐.
  필요해지면 `NSCache` 래핑으로 충족되며, 라이브러리는 디스크 캐시·프로세서 체인 등 미사용 기능을 함께 들여옴
- **네트워크 라이브러리(Alamofire 등)** — 요청 2종뿐이라 URLSession 래핑으로 충분. 테스트도 URLProtocol 로 가능
- **DI 컨테이너** — 런타임 해석으로 컴파일 안전성 상실. Composition Root 수동 조립으로 충분
- **스냅샷 테스트 라이브러리** — UI 완성도가 평가 대상이 아니며 기준 이미지 관리 비용 발생

## 트레이드오프
- 직접 구현 부분의 검증 책임 발생 → 테스트로 보완
- 이미지 캐시 미도입. 셀 재사용마다 재요청
